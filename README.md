# وربيرة — متجر مستلزمات الحيوانات الأليفة (HTML / CSS / JS)

موقع متجر إلكتروني كامل بدون أي إطار عمل (لا React ولا Next.js) — HTML5 و CSS3 و
JavaScript خالص، يعمل مباشرة بفتح الملفات في المتصفح أو برفعه على أي استضافة
عادية (بما فيها استضافة ملفات ثابتة مجانية).

## هيكل المشروع

```
/index.html        الرئيسية
/products.html      المتجر (بحث + فلاتر + ترتيب)
/product.html       تفاصيل منتج واحد (?id=...)
/cart.html          السلة وإتمام الطلب عبر واتساب
/about.html         من نحن
/contact.html       تواصل معنا
/login.html         تسجيل دخول الأدمن
/admin.html         لوحة تحكم الأدمن

/css/style.css      كل التنسيقات

/js/config.js       ⭐ رقم واتساب، انستغرام، بيانات الأدمن الافتراضية
/js/icons.js        أيقونات SVG المستخدمة في كل الموقع
/js/store.js        طبقة تخزين البيانات (localStorage) — منتجات/أقسام/إعدادات/سلة
/js/whatsapp.js      تنسيق العملة وبناء روابط واتساب
/js/app.js          الهيدر والفوتر المشتركين وعداد السلة
/js/products.js     شبكة المنتجات، البحث، الفلاتر، صفحة التفاصيل
/js/cart.js         منطق صفحة السلة
/js/auth.js         تسجيل دخول الأدمن وحماية لوحة التحكم
/js/admin.js        لوحة التحكم بالكامل (منتجات/أقسام/طلبات/إعدادات)

/assets/logo/logo.png   الشعار المرفوع
```

## كيف تشغّل الموقع

- **الأسهل:** افتح `index.html` مباشرة في المتصفح (يعمل بدون خادم).
- **للنشر:** ارفع كل الملفات كما هي إلى أي استضافة ثابتة (مثل GitHub Pages,
  Netlify, Vercel كموقع ثابت، أو استضافة مشتركة عادية). لا حاجة لأي إعداد
  خادم أو قاعدة بيانات خارجية.

## أين أغيّر رقم واتساب أو حساب انستغرام؟

طريقتان:

1. **من لوحة التحكم مباشرة (الطريقة الموصى بها):** سجّل دخول من `login.html`
   ثم من تبويب "الإعدادات" غيّر رقم واتساب، رابط انستغرام، الهاتف، ساعات
   العمل، معلومات التوصيل... الخ. يُحفظ التغيير فورًا ويظهر في كل الموقع.

2. **القيمة الافتراضية عند أول زيارة فقط:** عدّل `js/config.js` — هذا الملف
   يُستخدم فقط لتهيئة البيانات أول مرة (قبل أي حفظ من لوحة التحكم). إن كنت قد
   بدأت التصفح فعلًا، التعديل من لوحة التحكم هو الذي يسري.

## بيانات دخول الأدمن الافتراضية

- اسم المستخدم: `admin`
- كلمة المرور: `PetShop@2025`

**غيّرها فورًا** من تبويب الإعدادات في لوحة التحكم بعد أول دخول.

## ⚠️ ملاحظة أمان مهمة (اقرأها بعناية)

هذا المشروع HTML/CSS/JS خالص بدون أي خادم خلفي (backend) وبدون قاعدة بيانات
حقيقية — كما طلبت. هذا يعني:

- كل البيانات (المنتجات، الأقسام، الإعدادات، بيانات دخول الأدمن) مخزّنة في
  **localStorage الخاص بالمتصفح**، وليست على خادم مركزي.
- تسجيل دخول الأدمن هو **تحقق من جهة العميل فقط** (JavaScript يقارن القيمة
  المُدخلة بالقيمة المخزنة في نفس المتصفح). هذا يمنع الزوار العاديين من فتح
  لوحة التحكم بالصدفة، لكنه **ليس نظام مصادقة حقيقيًا** — أي شخص لديه معرفة
  تقنية بسيطة يمكنه فتح أدوات المطوّر في متصفحه وقراءة القيمة المخزّنة.
- **الأهم:** لأن البيانات محلية في المتصفح، فإن التغييرات التي تجريها من جهاز
  (مثل إضافة منتج) **لا تظهر تلقائيًا لزوار آخرين يفتحون الموقع من أجهزتهم**،
  لأن كل متصفح له نسخة localStorage مستقلة خاصة به. هذا الإصدار مناسب
  كـ **نموذج عملي كامل الوظائف (demo / MVP) وللاختبار والعرض**، وليس كمتجر
  إنتاجي متعدد الزوار بعد.

### إن أردت متجرًا حقيقيًا يشاهد فيه كل الزوار نفس المنتجات:

طُوّر الكود بحيث كل القراءة والكتابة تمر حصرًا عبر ملف واحد هو `js/store.js`
(دوال مثل `Store.getProducts()` و`Store.addProduct()`...). لذلك للترقية لاحقًا
إلى قاعدة بيانات حقيقية (مثل Supabase) يكفي استبدال محتوى دوال هذا الملف بنداءات
API حقيقية، دون تعديل أي صفحة أو ملف آخر في الموقع. أخبرني إن أردت المساعدة في
هذه الخطوة لاحقًا.

## العملة

جميع الأسعار مخزّنة كأرقام صحيحة (دينار عراقي) وتُنسَّق تلقائيًا عند العرض
(مثال: `10000` → `10,000 د.ع`). رمز العملة نفسه قابل للتغيير من الإعدادات.

## ماذا يحدث عند الضغط على "طلب عبر واتساب"؟

يُفتح واتساب (تطبيق أو ويب) على المحادثة مع الرقم المسجّل في الإعدادات، مع
رسالة جاهزة تحتوي اسم/أسعار/كميات المنتجات والمجموع الكلي — يكمل العميل بعدها
تفاصيل التوصيل مع المتجر مباشرة داخل واتساب.

## اختبار سريع قبل الاستخدام الفعلي

1. افتح الموقع وتصفّح المنتجات — تأكد من ظهور بيانات القسم والسعر بشكل صحيح.
2. أضف منتجًا للسلة وجرّب زر "طلب عبر واتساب" من صفحة التفاصيل ومن السلة.
3. سجّل دخول الأدمن (`login.html`) بالبيانات الافتراضية أعلاه.
4. جرّب إضافة/تعديل/حذف منتج وقسم، وتأكد من ظهور التغيير فورًا في المتجر
   (بنفس المتصفح).
5. من تبويب الإعدادات: غيّر رقم واتساب وكلمة مرور الأدمن، ثم سجّل خروج
   وادخل بالبيانات الجديدة للتأكد.
